Parte 1 – Folha de Estilos (CSS): Estilos de fontes

1

1. Explique o que é CSS e qual é a sua importância no desenvolvimento de páginas web. Apresente um exemplo de como o CSS pode melhorar a aparência de um documento HTML.

Resposta simples: O CSS (Folhas de Estilo em Cascata) é a linguagem que define as cores, fontes, tamanhos, espaçamentos e todo o visual de um site. Ele é fundamental porque separa a estrutura (HTML) da aparência (CSS), permitindo criar páginas modernas e fáceis de manter.

Exemplo prático:

Título Estilizado com CSS

h1 {
  color: #1d4ed8;
  font-family: Arial, sans-serif;
  text-align: center;
}
2

2. Explique a diferença entre as propriedades font-family, font-size e font-weight. Apresente um exemplo de código utilizando as três propriedades em um título.

Resposta simples:

  • font-family: Escolhe o tipo/família da letra (ex: Arial, Georgia).
  • font-size: Define o tamanho da letra (ex: 28px).
  • font-weight: Define a grossura da letra (normal ou negrito/bold).
Exemplo em um título: 
h1 {
  font-family: 'Segoe UI', Tahoma, sans-serif; /* Tipo da fonte */
  font-size: 28px;                             /* Tamanho */
  font-weight: bold;                           /* Negrito */
}

Resposta simples: Basta aplicar as propriedades font-family, font-size, font-weight e color no seletor do título.

Título da Questão 3

h1 {
  font-family: Arial, sans-serif;
  font-size: 32px;
  font-weight: bold;
  color: blue; /* ou #1d4ed8 */
}

4. Explique a diferença entre as propriedades font-style e text-decoration. Apresente um exemplo de utilização de cada uma delas.

Resposta simples:

  • font-style: Modifica a inclinação da letra (deixando em itálico).
  • text-decoration: Adiciona linhas decorativas (sublinhado embaixo ou riscado no meio).

Exemplo com font-style: italic (letra inclinada)

Exemplo com text-decoration: underline (linha embaixo)

.citacao { font-style: italic; }
.destaque { text-decoration: underline; }

6. Explique como a escolha das fontes pode influenciar a legibilidade, a acessibilidade e a experiência do usuário em um site. Cite duas boas práticas para a escolha de fontes.

Resposta simples: Fontes fáceis de ler não cansam os olhos do usuário (legibilidade), ajudam pessoas com dificuldades visuais a distinguir as letras (acessibilidade) e transmitem a seriedade ou descontração da marca (experiência do usuário).

Duas boas práticas:

  1. Usar fontes sem serifa (sans-serif) para blocos de texto em telas.
  2. Não misturar mais de 2 ou 3 tipos de fontes no mesmo site.

Parte 2 – Estilos de linhas

7

7. Explique a finalidade da propriedade line-height no CSS. Apresente um exemplo de código que melhore o espaçamento entre as linhas de um parágrafo.

Resposta simples: O line-height define a altura da linha, ou seja, o espaço vertical entre uma linha e outra do mesmo texto. Ele evita que as linhas fiquem coladas, tornando a leitura muito mais agradável.

Este parágrafo possui line-height: 1.8. Observe como o espaço vertical entre as linhas deixa o texto muito mais confortável para ler na tela. 

p {
  font-size: 16px;
  line-height: 1.8; /* Espaçamento agradável entre linhas */
}
8

8. Qual é a diferença entre as propriedades border, border-width, border-style e border-color? Explique e apresente um exemplo de utilização.

Resposta simples:

  • border-width: Define apenas a grossura da linha (ex: 2px).
  • border-style: Define apenas o tipo do traço (sólido, tracejado, pontilhado). É obrigatório!
  • border-color: Define apenas a cor da borda.
  • border: O atalho prático que configura grossura, estilo e cor tudo junto.
/* Atalho prático */
.caixa {
  border: 2px solid #000000; /* largura, estilo e cor */
}

Caixa com borda sólida preta de 2px, border-radius: 8px e padding: 15px. 
.caixa {
  border: 2px solid black; /* Borda sólida preta de 2px */
  border-radius: 8px;      /* Cantos arredondados */

}

10. Explique a diferença entre as propriedades margin e padding. Utilize um exemplo prático para demonstrar como cada uma interfere no posicionamento e no espaçamento dos elementos.

Resposta simples:

  • Padding (interno): É o espaço de dentro da caixa. Fica entre o texto e a borda.
  • Margin (externo): É o espaço de fora da caixa. Empurra os outros elementos para longe.

Caixa Cinza Externa: Tem margin afastando dos outros e padding afastando a caixa interna.

Caixa Branca Interna: Conteúdo protegido pelo padding. 
.card {
  padding: 20px; /* Afasta o texto da borda do cartão */
  margin: 15px;  /* Afasta o cartão dos outros elementos */
}

Parte 3 – Eventos

13

13. Explique o que são eventos em páginas web e qual é a função do JavaScript na identificação e no tratamento desses eventos.

Resposta simples: Eventos são ações que acontecem na página (como o usuário clicar, mover o mouse ou preencher um campo). O JavaScript é o "cérebro" que monitora esses eventos e executa funções imediatas de resposta, tornando o site dinâmico e interativo sem recarregar a página.

14

14. Explique a diferença entre os eventos click, mouseover e mouseout. Apresente uma situação em que cada um deles poderia ser utilizado.

Resposta simples e situações:

  • click: Ocorre quando o usuário clica no elemento. Exemplo: Botão de comprar ou curtir.
  • mouseover: Ocorre quando a seta do mouse entra em cima do elemento. Exemplo: Abrir um menu suspenso ou dar zoom em foto.
  • mouseout: Ocorre quando a seta do mouse sai de cima do elemento. Exemplo: Fechar o menu suspenso e voltar a foto ao normal.

Texto inicial antes do clique.

16. Crie um exemplo em que a cor de fundo de um botão seja alterada quando o usuário passar o mouse sobre ele e retorne à cor original quando o mouse sair. Utilize eventos JavaScript e CSS.

(Mouse fora do botão) 
const btn = document.getElementById('btn-q16');

// Mouse entra: fica laranja

// Mouse sai: volta ao cinza original

  btn.style.backgroundColor = '#475569';

17. Explique a diferença entre utilizar eventos diretamente no HTML, como onclick, e utilizar o método addEventListener() no JavaScript. Cite uma vantagem de utilizar addEventListener().

Resposta simples: O onclick no HTML mistura código de programação direto na marcação visual. Já o addEventListener() é colocado no arquivo JavaScript, mantendo tudo limpo e organizado.

Vantagem do addEventListener(): Permite adicionar vários ouvintes e ações diferentes para o mesmo evento no mesmo botão sem dar conflito.

18. Desenvolva um formulário com um campo para o nome do usuário e um botão. Ao clicar no botão, o programa deverá exibir uma mensagem de boas-vindas com o nome digitado. Explique como o evento de clique é tratado.

btn.addEventListener('click', function() {
  const nome = campoNome.value.trim();
  if (nome !== '') {
    msg.textContent = `Olá, ${nome}! Seja muito bem-vindo(a)!`;
  }
});

Como o evento é tratado: O JavaScript escuta o clique do botão com addEventListener('click'), lê o valor do campo com .value e altera o texto do parágrafo de mensagem com .textContent.

Parte 4 – Responsividade: Criação de layouts

19

19. Explique o conceito de responsividade no desenvolvimento Front-End. Por que um site precisa se adaptar a computadores, tablets e celulares?

Resposta simples: Responsividade é fazer a página se ajustar e reorganizar os elementos para qualquer tamanho de tela. É obrigatório porque a maior parte dos acessos hoje vem de celulares; se o site não se adaptar, o usuário precisa dar zoom e rolar a página pros lados, o que causa frustração e abandono do site.

20

20. Explique a função da regra @media no CSS e apresente um exemplo em que o tamanho da fonte de um título seja reduzido quando a largura da tela for igual ou inferior a 600 pixels.

Resposta simples: A regra @media aplica estilos específicos apenas quando a tela atingir determinada largura (como no celular).

/* Tamanho normal para telas grandes */
h1 {
  font-size: 32px;
}

/* Telas até 600px (celulares): diminui o título */
@media (max-width: 600px) {
  h1 {
    font-size: 20px;
  }
}

22

22. Explique a diferença entre utilizar unidades fixas, como px, e unidades relativas, como %, em, rem, vw e vh. Apresente exemplos de situações em que essas unidades podem ser úteis.

Resposta simples e situações:

  • px (fixo): Tamanho que nunca muda. Útil para bordas de 1px ou 2px.
  • % (relativo): Proporcional ao elemento pai. Útil para largura de colunas (ex: width: 50%).
  • rem (relativo): Baseado na fonte padrão da página. É a melhor unidade para fontes acessíveis.
  • vw e vh: Proporcionais à largura (vw) e altura (vh) da janela do navegador. Útil para banners de tela cheia (100vh).

23. Crie um layout responsivo para uma página que contenha um cabeçalho, um menu de navegação, uma área principal e um rodapé. Explique como você organizaria esses elementos em telas grandes e pequenas.

Organização:

  • Em telas grandes (desktop): Cabeçalho e menu lado a lado no topo horizontal; conteúdo central pode ter colunas; rodapé com links distribuídos.
  • Em telas pequenas (celular): Todos os blocos ficam empilhados em coluna única na vertical para facilitar a rolagem com o dedo e não esmagar os textos.
24

24. Explique como as propriedades display: flex, flex-wrap e justify-content podem ajudar na criação de layouts responsivos. Apresente um exemplo de código que utilize essas propriedades.

Resposta simples:

  • display: flex: Coloca os itens filhos alinhados lado a lado automaticamente.
  • flex-wrap: wrap: Permite que os itens pulem para a linha de baixo quando não houver mais espaço na tela.
  • justify-content: Controla a distribuição do espaço entre os itens (ex: espalhados ou centralizados).
.container-flex {
  display: flex;                  /* Alinha os itens em linha */
  flex-wrap: wrap;                /* Quebra de linha se a tela for pequena */
  justify-content: space-between; /* Espalha os itens de ponta a ponta */
}

Parte 5 – Responsividade: Código semântico

25

25. Explique o que é HTML semântico e por que é importante utilizar elementos que representem corretamente o significado do conteúdo de uma página.

Resposta simples: HTML semântico é usar tags que explicam o que o conteúdo é (como <header> para topo e <footer> para rodapé), em vez de usar apenas <div> para tudo. É importante para o Google entender a página e para pessoas com deficiência visual navegarem por leitores de tela.

26

26. Explique a finalidade das tags <header>, <nav>, <main>, <section> e <footer>. Apresente uma situação de uso para cada uma delas.

Finalidade e situações de uso:

  • <header>: Cabeçalho do site. Uso: Logotipo e título principal.
  • <nav>: Menu de links. Uso: Links para "Início", "Sobre", "Contato".
  • <main>: Conteúdo principal e exclusivo da página. Uso: O texto da notícia ou produtos.
  • <section>: Seção temática de assunto. Uso: Seção "Depoimentos" ou "Planos".
  • <footer>: Rodapé da página. Uso: Direitos autorais e redes sociais.
27

27. Observe a estrutura abaixo e explique quais problemas podem existir na utilização excessiva de elementos <div>. Em seguida, reescreva o exemplo utilizando tags semânticas adequadas.

Problemas da "Divite": O código fica desorganizado e confuso para quem programa, os motores de busca do Google não entendem a hierarquia e os leitores de tela não conseguem orientar deficientes visuais.

Reescrita semântica adequada: 
<header>
  <h1>Minha página</h1>
  <nav>
    <a href="#inicio">Início</a>
    <a href="#sobre">Sobre</a>
    <a href="#contato">Contato</a>
  </nav>
</header>

<main>
  <p>Conteúdo principal</p>
</main>

<footer>
  <p>Rodapé</p>
</footer>
28

28. Explique como o uso de HTML semântico pode contribuir para a acessibilidade e para a compreensão da estrutura de uma página por mecanismos de busca. Cite pelo menos três benefícios.

Três benefícios:

  1. Navegação facilitada para cegos: Os leitores de tela conseguem pular direto para a tag <main> sem ter que reouvir o menu inteiro.
  2. Melhor SEO no Google: O Google entende perfeitamente o que é o título importante (<h1>) e o artigo (<article>), melhorando a posição do site.
  3. Código limpo e fácil de manter: Qualquer programador bate o olho e sabe para que serve cada bloco.
